项目名称：STM32F407 双分区 IAP Bootloader 及串口升级系统（个人项目）

项目描述：为 STM32F407ZG（1MB Flash）设计的固件在线升级（IAP）系统。自定义串口升级协议配合 A/B 双 App 分区与双扇区冗余元数据，实现"升级中途掉电、重启后仍运行旧固件"的可靠性目标，含固件版本防回滚;Flash 布局：Bootloader 128K / 槽 A 512K / 槽 B 384K / 元数据双扇区。

采用技术：C、STM32 HAL、Flash IAP、串口协议设计

项目职责：
设计并实现自定义串口升级协议（含收发两端）：AA55 帧同步字 + 分包头（序号/长度/分包 CRC32）+ 停等式 ACK/NACK 重传，解决字节流错位、半包超时、丢包重传问题，错位后可自动重获帧边界；
设计 A/B 双分区与双扇区冗余元数据的掉电保护方案：槽状态按 Flash"只能清位"特性用位梯子编码原地编程、记录级 CRC 仅覆盖一次写定字段、双副本按代际号仲裁（先验 CRC 后比号），升级中断电后设备重启仍运行旧固件，并含防回滚校验；
实现 App 主动请求升级：串口命令写入 RTC 备份寄存器后复位，Bootloader 识别留言并打开加长升级窗口；升级失败后 Bootloader 常驻监听，无需人工复位即可重试。
